# Phase II reference material (local only)

This folder holds local copies of the course documents used as the baseline for Phase III:

* `annotated-Intelligent Route Planning System Phase II Project Design.pdf`: the team's Phase II design (schema, sample data, ten views, ER diagram)
* `Data management Projects info sheet_F26 (1).pdf`: the official project requirements
* `SOFE 3700U Project Review – What We Expect.pdf`: the TA's review checklist

The PDFs are **git-ignored** (`docs/phase2-reference/*.pdf`). They contain student names and numbers and
course material, so they are not published with the source code. The implemented SQL in `database/` follows
the Phase II design; `docs/TEST_RESULTS.md` (§6) documents the few deliberate deviations: fictional demo
identities, real password hashes and identity-sequence resets.
